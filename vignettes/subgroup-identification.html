Aggregate subgroup information for the relaxed model

The relaxed model gives the index and comparator treatments separate covariate coefficients. The IPD identify beta_index; the comparator coefficients are informed only through the aggregate likelihood, so what they can be pinned down to depends on how many aggregate rows there are and how those rows are laid out. This vignette shows what check_identification() measures, how to read it, and what a simulation says about designs that pass the row count and still fail.

What an aggregate row contributes

For the binomial, normal and Poisson families each mutually exclusive aggregate stratum contributes one scalar outcome summary. With \(K\) covariates the relaxed comparator model has \(K + 1\) coefficients, so \(S \geq K + 1\) rows are necessary. They are not sufficient. For a normal identity-link model stratum \(s\) has mean \(\bar y_s = \mu_c + m_s^\mathsf{T}\beta_c\), where \(m_s\) is the declared covariate-mean vector, and the coefficients are separated only when the design \([\mathbf{1}, M]\) has full column rank: after centering, the mean vectors must span all \(K\) covariate directions. For a nonlinear mean model each row contributes \(\mathbb{E}_{X\sim f_s}[g^{-1}(\mu_c+X^\mathsf{T}\beta_c)]\), which depends on the whole within-stratum distribution \(f_s\), so the mean-profile geometry is descriptive there and check_identification() returns flagged = NA once the row count is adequate (Phillippo et al. 2020; C. Chandler and Ishak 2026).

Multiple set_agd() rows are taken to be mutually exclusive, collectively exhaustive strata of one comparator population, combined with outcome_n or person-time weights; they are not overlapping subgroup analyses. If Poisson exposure varies with the covariates, the covariate summaries must match the person-time distribution (Remiro-Azocar et al. 2022).

Mean-profile geometry

check_identification() centers the declared subgroup means, divides each covariate by its IPD SD, and takes the singular values. cond_inv, the smallest over the largest, goes to zero as the rows collapse onto a lower-dimensional set; spread, the RMS distance of the rows from their center along the dominant direction, says whether they move at all.

library(mlumr)

One continuous and two binary covariates. The designs below all have several rows but span different directions.

ref_sd <- c(age = 1, sex = 0.5, prior = 0.49)

by_age_only <- cbind(age = seq(-1.5, 1.5, length.out = 6), sex = 0.5, prior = 0.4)
cross_tab <- rbind(c(0, 0, 0), c(0, 1, 0), c(0, 0, 1), c(0, 1, 1))
jointly_defined <- rbind(c(-1, 0, 0), c(-1, 1, 0), c(-1, 0, 1), c(-1, 1, 1),
                         c(1, 0, 0), c(1, 1, 1))

geometry <- function(M) {
  M <- scale(as.matrix(M), center = TRUE, scale = FALSE)
  M <- sweep(M, 2, ref_sd, "/")
  d <- svd(M)$d
  c(rows = nrow(M), cond_inv = round(min(d) / max(d), 3),
    spread = round(max(d) / sqrt(nrow(M)), 3))
}
rbind(by_age_only = geometry(by_age_only), cross_tab = geometry(cross_tab),
      jointly_defined = geometry(jointly_defined))
#>                 rows cond_inv spread
#> by_age_only        6    0.000  1.025
#> cross_tab          4    0.000  1.020
#> jointly_defined    6    0.707  1.167

Age bands vary only in the age direction and the cross-tab holds age fixed; only the jointly defined cells span all three covariates. More rows along an existing direction cannot replace a missing one.

Using check_identification()

The screen uses the declared AgD means, so it can be run before add_integration().

set.seed(2026)
n_ipd <- 120
ipd_df <- data.frame(
  trt = "A",
  y = rnorm(n_ipd, 2, 1),
  age = rnorm(n_ipd),
  sex = rbinom(n_ipd, 1, 0.5),
  prior = rbinom(n_ipd, 1, 0.4)
)
ipd <- set_ipd(ipd_df, treatment = "trt", outcome = "y",
               covariates = c("age", "sex", "prior"), family = "normal")

make_design <- function(M) {
  agd_df <- data.frame(
    trt = "B",
    n = rep(100, nrow(M)),
    ybar = 2 + 0.1 * M[, 1] + 0.2 * M[, 2] - 0.1 * M[, 3],
    yse = rep(0.1, nrow(M)),
    age_mean = M[, 1],
    age_sd = rep(1, nrow(M)),
    sex_mean = M[, 2],
    prior_mean = M[, 3]
  )
  agd <- set_agd(
    agd_df, treatment = "trt", family = "normal",
    outcome_mean = "ybar", outcome_se = "yse", outcome_n = "n",
    cov_means = c("age_mean", "sex_mean", "prior_mean"),
    cov_sds = c("age_sd", NA, NA),
    cov_types = c("continuous", "binary", "binary")
  )
  combine_data(ipd, agd)
}

identity_age <- check_identification(
  make_design(by_age_only), link = "identity", verbose = FALSE
)
identity_joint <- check_identification(
  make_design(jointly_defined), link = "identity", verbose = FALSE
)
nonlinear_joint <- check_identification(
  make_design(jointly_defined), link = "log", verbose = FALSE
)

data.frame(
  design = c("age only", "joint identity", "joint log"),
  scope = c(identity_age$diagnostic_scope,
            identity_joint$diagnostic_scope,
            nonlinear_joint$diagnostic_scope),
  rows = c(identity_age$n_rows, identity_joint$n_rows,
           nonlinear_joint$n_rows),
  cond_inv = c(identity_age$cond_inv, identity_joint$cond_inv,
               nonlinear_joint$cond_inv),
  spread = c(identity_age$spread, identity_joint$spread,
             nonlinear_joint$spread),
  flagged = c(identity_age$flagged, identity_joint$flagged,
              nonlinear_joint$flagged)
)

The thresholds cond_inv < 0.2 and spread < 0.05 IPD SD are package heuristics for the identity-link design, not validated cutoffs. Neither statistic sees subgroup sample sizes, outcome precision or link curvature, so a value above the threshold does not prove identification.

Recommended workflow

  1. Check that the rows are mutually exclusive, collectively exhaustive strata of the comparator population, with sample sizes or exposures.
  2. Count the rows against \(K + 1\).
  3. For a normal identity-link model read cond_inv and spread; when the design is deficient, request jointly defined cells that vary across all covariates.
  4. For a nonlinear model treat the geometry as descriptive and read the fitted coefficient posterior, the sampler diagnostics and prior_sensitivity().
  5. Run check_integration() separately; numerical fidelity of the grid and identification are different questions.
  6. Check overlap before transporting the comparator regression to another population (Phillippo et al. 2016; Conor Chandler and Ishak 2026).

Distribution and dependence assumptions

Each nonlinear aggregate likelihood integrates over a reconstructed within-stratum covariate distribution, which means, SDs and a copula do not uniquely determine, and the same correlation matrix is reused for every row. These are sensitivity assumptions, not something a row count repairs: vary plausible marginals and dependence structures when the estimand is sensitive to them.

Time-to-event outcomes

A comparator curve from set_agd_surv() contributes event and censoring terms across time, not one scalar summary per row, so the counting argument does not apply and check_identification() refuses survival data. For a relaxed survival fit inspect the comparator coefficient posterior, run prior_sensitivity() with prior_beta_comparator_scales, and compare aux_by = ".study" with aux_by = "none" where that is defensible.

Each row is that design minus the four-row minimal_4, over the replications where both converged; a positive difference is a wider interval.

Three things follow.

Row count does not order the designs; geometry does. The six-row one-variable-at-a-time design has more rows than the four-row minimal design and gives a wider interval in every family. A reader counting rows would prefer the worse design.

An unidentified design is unpredictable, not merely imprecise. The coefficient of variation of the width separates the two groups completely: every identified cell is at or below 0.05 and every deficient one at or above 0.16. Coverage shows none of this, because a wide enough interval covers almost anything.

The screen is exact under the identity link and silent elsewhere. Across the 1800 normal fits check_identification() flagged exactly the deficient designs. Under the logit and log links it withholds a verdict for the deficient designs that have rows enough, and the sampler does not reliably cover that gap: of the 1200 such fits, 943 met every diagnostic. All 258 fits that failed a diagnostic belong to the deficient group, and every one of them is binomial or Poisson. A clean set of diagnostics is not evidence that the design is identified; compute the geometry from the aggregate table before fitting.

What this vignette does not claim

There is no universal minimum number of rows beyond \(K + 1\), no validated cond_inv cutoff, and no guarantee that an unflagged design gives a precise target effect. The simulation uses synthetic strata, six designs, three covariates, one effect size and no survival family; what it establishes is the inversion, for which one counterexample is enough. A threshold for a specific application would need that application’s within-stratum distributions, effect size, sample sizes and outcome family.

# Evaluate a mlumr_distr object with data context

Evaluate a mlumr_distr object with data context

## Usage

``` r
eval_distr(d, p, data = list())
```

## Arguments

- d:

  A `mlumr_distr` object

- p:

  Vector of probabilities

- data:

  A named list or data frame to evaluate expressions in

## Value

Numeric vector of quantiles

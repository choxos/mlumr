# Note, inline, that a printed statistic was computed without some parameters

Note, inline, that a printed statistic was computed without some
parameters

## Usage

``` r
.missing_suffix(d)
```

## Arguments

- d:

  A
  [`.usable_diagnostic_values()`](https://choxos.github.io/mlumr/reference/dot-usable_diagnostic_values.md)
  result.

## Value

A single string, empty when nothing was missing.

# Link function (response scale -\> linear predictor)

Link function (response scale -\> linear predictor)

## Usage

``` r
link_fun(x, link = c("identity", "log", "logit", "probit", "cloglog"))
```

## Arguments

- x:

  Numeric vector on response scale

- link:

  Character: link function name

## Value

Numeric vector on linear predictor scale

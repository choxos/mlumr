# Warn when the median is being read off the first grid interval

Warn when the median is being read off the first grid interval

## Usage

``` r
.warn_early_median(shares)
```

## Arguments

- shares:

  Per-curve values of
  [`.median_early_share()`](https://choxos.github.io/mlumr/reference/dot-median_early_share.md).

# The one scalar `effect` name a survival fit can supply

The one scalar `effect` name a survival fit can supply

## Usage

``` r
.surv_scalar_effect_name(label)
```

## Arguments

- label:

  The `label` from
  [`.surv_scalar_label()`](https://choxos.github.io/mlumr/reference/dot-surv_scalar_label.md)
  (natural scale).

## Value

One of `"hr"`, `"tr"`, `"exp_delta_eta"`.

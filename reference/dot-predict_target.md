# Absolute predictions standardized to an arbitrary target population

Internal dispatch for
[`predict.mlumr_fit()`](https://choxos.github.io/mlumr/reference/predict.mlumr_fit.md)
when `newdata` is supplied. g-computation of per-treatment absolute
outcomes over the target covariate distribution.

## Usage

``` r
.predict_target(object, newdata, type, summary, probs, times)
```

# Inverse link function (linear predictor -\> response scale)

Inverse link function (linear predictor -\> response scale)

## Usage

``` r
inverse_link(x, link = c("identity", "log", "logit", "probit", "cloglog"))
```

## Arguments

- x:

  Numeric vector

- link:

  Character: link function name

## Value

Numeric vector on response scale

# Store user priors plus the resolved Stan-scale beta prior

Store user priors plus the resolved Stan-scale beta prior

## Usage

``` r
.mlumr_prior_metadata(
  data,
  family,
  model = "spfa",
  prior_intercept,
  prior_beta,
  prior_beta_comparator = NULL,
  prior_sigma,
  beta_fields,
  beta_comparator_fields = NULL,
  sd_x,
  prior_aux = NULL,
  prior_smooth = NULL,
  surv_info = NULL
)
```
